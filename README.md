# Rugero Fidele — Developer Portfolio

Minimal, terminal-inspired portfolio built with React, Vite, and Tailwind CSS.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

## Customize

Edit `src/data/siteData.js` to update:

- Contact email and LinkedIn URL
- Tech stack
- Project descriptions and links

## Deploy

```bash
npm run build
```

Upload the `dist/` folder to any static host (Vercel, Netlify, GitHub Pages, etc.).
